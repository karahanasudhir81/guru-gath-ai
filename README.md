# Build a high-performance, full-stack AI Tutor web application with a modern, authentic Indian...

Build a high-performance, full-stack AI Tutor web application with a modern, authentic Indian aesthetic.

1. UI Theme & Visual Design (Indian Authentic View):

- Palette: Royal Navy/Deep Indigo base, Warm Amber/Saffron accents, Warm Ivory cards, Subtle Temple/Jali geometric lattice SVG patterns, and fine Gold trim highlights.

- Aesthetics: Sleek, high-end, clean glass morphism with cultural warmth (e.g., traditional welcome banners, lotus iconography, subtle mandala watermarks).

2. Landing Page & Public Navigation:

- Hero section with live demo preview, "Try Interactive Tutor" CTA button, and real-time audio wave animation.

- Features Section: Highlighting Voice AI, 24/7 Agent Availability, Multi-subject Mastery, Session Recording, and Native Language support.

- Pricing Tier Section: Free Trial ($0), Pro Student ($15/mo), and Master Scholar ($29/mo) cards with feature checklists and toggle for monthly/annual billing.

- Footer with Indian language selector (Hindi, Tamil, Telugu, Bengali, English).

3. Multi-Agent Ecosystem (Initial 4 Agents + Expandable Architecture):

- Agent 1: "Arya" – General Academic & STEM Tutor (Patient, step-by-step problem solver).

- Agent 2: "Bhasha Coach" – Conversational Language & Speech Assistant (Accent, vocabulary, and phonetic guide).

- Agent 3: "Saraswati" – Humanities & Exam Prep Guide (UPSC, Board Exams, Essay feedback).

- Agent 4: "Yukti" – Logical Reasoning & Coding Mentor (Algorithmic practice and logic puzzles).

- Include an expandable "Add New Custom AI Agent" architectural button in the dashboard for future scaling.

4. Interactive Tutor Hub & Chat Workspace:

- Agent Selection Carousel: Switch between Arya, Bhasha, Saraswati, and Yukti with individual avatars and specialized chat contexts.

- Interactive Chat UI: Real-time dynamic messaging with rich Markdown rendering.

- Voice Input & Audio Controls: Microphone button with Web Speech API integration for direct speech-to-text input, plus Text-to-Speech audio output.

- Recording & Memory Saving: "Save Session Summary" button and "Record Audio Conversation" toggle with downloadable transcripts (.txt/PDF).

- File Upload & Analysis: Upload options for student notes, PDF worksheets, and images (OCR support for mathematical formulas/symbols).

- Math & Symbol Palette: Quick-insert drawer for Greek letters, LaTeX symbols, and Indian currency/notation.

5. Student Database & User Authentication:

- User Authentication Flow: Email/Password signup, login modal, and profile avatar menu.

- Student Dashboard & Memory Database: Track recent study chats, stored session recordings, saved notes, subject progress metrics, and flashcards.

- Live Help / Support Widget: Embedded floating live help button on the bottom right for platform feedback or human support queries.
